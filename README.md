# Anh Và Em 💞

Trang kỷ niệm ngày yêu nhau — đếm số ngày bên nhau, đồng hồ thời gian thực và hiệu ứng trái tim bay khi chạm/click.

Xây dựng bằng **vanilla HTML/CSS/JS + Bootstrap 5 CSS**, không cần build, không cần backend.

## Tính năng

- Đếm ngày yêu nhau (từ ngày bắt đầu đến hiện tại)
- Đồng hồ thời gian yêu nhau cập nhật realtime (ngày/giờ/phút/giây)
- Hiệu ứng trái tim + mây bay khi tương tác với trang

## Chạy

Không cần cài đặt gì — mở trực tiếp `index.html` trong trình duyệt:

```bash
open index.html
```

Hoặc chạy server tĩnh (tuỳ chọn):

```bash
npx serve .
```

## Cấu trúc

```
index.html   # Trang chính
style.css    # Toàn bộ style + animation
app.js       # Logic đếm ngày, đồng hồ, hiệu ứng tim
assets/      # Hình ảnh, tài nguyên
```
